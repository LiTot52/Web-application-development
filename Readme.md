## Цель работы

Настроить виртуальное пространство разработки, разработать контроллер веб-приложения и организовать маршруты (роутинг) с использованием фреймворка Django.

## Теоретическое обоснование

**Виртуальное окружение (venv)** - изолированное пространство Python, позволяющее устанавливать зависимости проекта отдельно от глобальной системы.

**Django** - высокоуровневый веб-фреймворк на Python (архитектура MVT), берущий на себя маршрутизацию запросов, работу с БД через ORM и рендеринг шаблонов.

**Контроллер (view)** - функция, принимающая объект запроса `request` и возвращающая HTTP-ответ.

**Маршрут (route)** - правило сопоставления URL с контроллером, описываемое в `urls.py` через `path()` и объединяемое между приложениями через `include()`.

## Выполнение практического примера

### Команды создания и настройки проекта

```bash
python -m venv venv
venv\Scripts\activate
pip install Django
django-admin startproject MySite
cd MySite
python manage.py runserver
python manage.py startapp news
```

### Код сервера

**`news/views.py`**
```python
from django.http import HttpResponse


def index(request):
    return HttpResponse('Hello, world!')


def test(request):
    return HttpResponse('<h1>Тестовая страница</h1>')
```

**`MySite/urls.py`**
```python
from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path('admin/', admin.site.urls),
    path('news/', include('news.urls')),
]
```

**`news/urls.py`**
```python
from django.urls import path
from .views import index, test

urlpatterns = [
    path('', index),
    path('test/', test),
]
```

## Контрольные вопросы

1. **Что такое клиент-серверная архитектура?**
Модель, при которой клиент отправляет запрос, а сервер обрабатывает его и возвращает ответ.

2. **Какой протокол используется для общения клиента и сервера?**
HTTP.

3. **Что такое маршрут в Django?**
URL-адрес, зарегистрированный в `urls.py` через `path()` и привязанный к функции-контроллеру.

4. **Что происходит при обращении к несуществующему адресу?**
Django возвращает ответ с кодом 404 (Page not found).

5. **Зачем используется `include()` в urls.py?**
Позволяет вынести маршруты приложения в отдельный файл и подключить их к общему списку маршрутов проекта.
