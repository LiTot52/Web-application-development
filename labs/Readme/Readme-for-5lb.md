## Цель работы

Научиться оформлять внешний вид HTML-шаблонов Django с помощью фреймворка Bootstrap, подключаемого через CDN; освоить работу с директивами, тегами (`for`, `if`, `cycle`, `now`) и фильтрами (`date`, `safe`, `linebreaks`, `truncatewords`) шаблонизатора; научиться вызывать методы модели из шаблона и выводить загруженные изображения.

## Теоретическое обоснование

**Bootstrap** - открытый и бесплатный HTML, CSS и JS фреймворк для быстрой вёрстки адаптивных сайтов и веб-приложений. Готовые компоненты (`navbar`, `card` и др.) подключаются через классы CSS, поэтому писать стили вручную не требуется.
 
**CDN (Content Delivery Network)** - географически распределённая сетевая инфраструктура, обеспечивающая быструю доставку контента пользователям. Серверы CDN расположены так, чтобы время ответа было минимальным. Благодаря CDN Bootstrap не нужно скачивать: достаточно подключить CSS и JS по ссылке.
 
**Три сущности шаблонизатора Django:**
 
| Сущность  | Синтаксис           | Назначение                                                      | Пример                                |
| --------- | ------------------- | --------------------------------------------------------------- | ------------------------------------- |
| Директивы | `{{ ... }}`         | Выводят значения переменных, переданных в шаблон через контекст | `{{ item.title }}`                    |
| Теги      | `{% ... %}`         | Управляют генерацией вывода (циклы, условия и т.д.)             | `{% for item in news %}`              |
| Фильтры   | `{{ value\|name }}` | Преобразуют значение перед выводом                              | `{{ item.created_at\|date:"Y-m-d" }}` |
 
**Используемые теги:**
 
| Тег                                   | Назначение                                                                                                 |
| ------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `{% for %}...{% endfor %}`            | Цикл по объектам. Внутри доступны переменные цикла, например `forloop.counter` (номер итерации с 1)        |
| `{% if %}...{% else %}...{% endif %}` | Условный вывод (например, показать фото или картинку-заглушку)                                             |
| `{% cycle 'a' 'b' %}`                 | При каждой встрече выдаёт очередной аргумент, после последнего возвращается к первому (чередование цветов) |
| `{% now 'Y-m-d H:i:s' %}`             | Выводит текущие дату и время в заданном формате                                                            |
 
**Используемые фильтры:**
 
| Фильтр               | Назначение                                                 |
| -------------------- | ---------------------------------------------------------- |
| `date:"Y-m-d H:i:s"` | Форматирует дату и время                                   |
| `safe`               | Помечает строку как безопасную, HTML в ней не экранируется |
| `linebreaks`         | Преобразует переводы строк в теги `<p>` и `<br>`           |
| `truncatewords:50`   | Обрезает текст до 50 слов и добавляет многоточие           |
 
**Вызов методов модели в шаблоне.** Шаблон имеет доступ не только к атрибутам объекта (`{{ item.category }}`), но и к его методам (`{{ item.my_func }}`). Скобки при вызове не пишутся, аргументы передать нельзя.
 
**Вывод изображений.** Адрес загруженного файла берётся из `item.photo.url`. Чтобы Django отдавал файлы из папки `media`, в `settings.py` задают `MEDIA_URL` и `MEDIA_ROOT`, а в `urls.py` подключают раздачу медиафайлов (в режиме отладки).
 
**Вспомогательные классы Bootstrap:** `container` (контейнер), `row` и `col-md-12` (сетка), `card`, `card-header`, `card-body`, `card-footer` (карточка), `mt-3`, `mb-3` (отступы сверху и снизу), `text-danger`, `text-success` (красный и зелёный цвет текста), `text-muted` (приглушённый текст).

## Вывод
 
В ходе лабораторной работы страница со списком новостей оформлена с помощью фреймворка Bootstrap, подключённого через CDN. Использованы компоненты Navbar и Card, сетка `container`/`row`/`col` и вспомогательные классы отступов и цвета. Изучены три сущности шаблонизатора Django: директивы, теги и фильтры. Применены теги `for`, `if`, `cycle`, `now`, переменная цикла `forloop.counter` и фильтры `date`, `safe`, `linebreaks`, `truncatewords`. В модель `News` добавлен метод, который вызван непосредственно из шаблона. Настроен вывод загруженных изображений через `item.photo.url` с запасной картинкой для новостей без фото, для этого заданы `MEDIA_URL`, `MEDIA_ROOT` и маршрут раздачи медиафайлов.
